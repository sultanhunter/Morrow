Morrow is a paid AI workspace where a Shopify brand's people and AI agents run the business
together: one standalone web workspace and a thin Shopify connector. The Coordinator scopes work,
specialist agents draft, people approve exact proposals, and one gateway executes, reads back and
audits. Agents work proactively toward goals, and merchants can install ready-made agents that
Morrow provides (OD-2026-10-22-1).

The launch target is a lean, full-featured MVP for shop owners rather than the invite-only
listings beta (OD-2026-10-22-2). Phase 1 adds its features, agents, skills, installation kinds,
tracks, gates and data classes under this node. `docs/graph/README.md` describes the graph.
