The owner's answer in chat on 2026-10-26 to the lead's reply to OD-2026-10-26-3, which recommended
keeping Morrow's harness on Anthropic's plain Messages API, with no Claude Agent SDK and no Claude
Managed Agents inside the product (ADR-0041, Context).

Effect:

1. **The recommendation stands.** No Claude Agent SDK and no Claude Managed Agents run in the
   product; the harness calls the Messages API through the broker (ADR-0041 item 1). ADR-0027's and
   ADR-0029's rule that no agent SDK runs in the product is unchanged.
2. **Conversations work like messaging a team of agents.** When a person sends a message, the
   agent receives it and answers with what it understood, what it is doing, or the result, instead
   of a reply streamed with a Stop button. ADR-0040 proposes how.
3. **The owner invited further architecture changes for it.** ADR-0040 and ADR-0041 propose them;
   this message approves neither record's text, values or trade-offs, which are put to the owner in
   Q-adr-0040-0041-owner-questions.
