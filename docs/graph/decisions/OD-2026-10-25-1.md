> use opus 5.5 high for the main agent and opus 5.5 medium for all type of subagents/specialists etc. and you can remove the cap on ai cost

The owner's answer to the lead's note that the agent loop's defaults were Morrow (the Coordinator)
on Opus 5.5 at high, specialists on Opus 5.5 at medium and the installed agents on Sonnet 5.5 at
low (ADR-0027 item 12), and that the unrecovered-cost cap of US$4.50 per workspace per billing
period blocks every Opus run before billing exists. The lead confirmed its reading to the owner in
chat; ADR-0036 records it.

Effect:
- Morrow, the main agent (the Coordinator), runs Opus 5.5 at high effort by default. Every other
  agent kind runs Opus 5.5 at medium effort by default: specialists, sub-agents and every installed
  agent, Listings, Business Analyst, Inventory, Marketing and Support included. The Owner still
  chooses each agent's model and effort (ADR-0027 item 12).
- The unrecovered-cost cap is removed for Listings and for loop runs.
- Kept: the per-run US$7 and per-day US$25 backstops, credit holds and reservations, the run
  breaker (three consecutive failed products), the owner's Anthropic monthly limit and every
  authority rule.
- Not confirmed by this answer: catalogue version 2's other values (prices, `max_tokens`, turn and
  tool limits), which stay proposed (Q-catalogue-v2-values); and catalogue version 3's default
  member ceiling of 4 (ADR-0036 item 2), which awaits the owner (Q-adr-0036-member-ceiling).
