> okay now for the 2 point : Answer four money questions for “credits are the only limit”.
> use the recommended options

The owner's answer in chat on 2026-10-26 to item 2 of the lead's
message, "Answer four money questions for 'credits are the only limit'", which put the four
readings of Q-adr-0039-carried-out-values, each with the lead's recommendation:

1. Failed jobs: should a job that fails still use up the credits it spent? Recommended: no, failed
   jobs are free.
2. A reserve for the last step: should each job keep one step's worth of credits aside, so a job
   that runs out still ends with an answer? Recommended: yes.
3. A maximum on a merchant's Shopify bill: keep the ceiling of twice the plan price per billing
   cycle on extra credit purchases? Recommended: keep it.
4. Per-agent limits: recommended, an optional credit limit the Owner can set per agent, off by
   default.

The lead replied in chat: failed jobs are free; a job keeps a reserve so that it can finish with an
answer; the ceiling of twice the plan price on Shopify credit purchases stays; an optional
per-agent credit limit that the Owner sets, off by default. The lead replied with the decision as
it is carried out, recorded here as the effect.

Effect:

1. **A loop run that fails draws nothing**, as ADR-0026 item 4's "Failed runs cost 0 credits"
   says; ADR-0039 item 2(g)'s proposed draw is not taken.
2. **The final-turn reserve stands** (ADR-0039 items 2(d) and 2(e)).
3. **`UsageCap`'s platform ceiling stays**: twice the plan price per billing cycle on extra credit
   purchases (ADR-0026 owner question 3).
4. **An optional per-agent credit limit** that the Owner sets, none by default (ADR-0039 item 7).

How each is carried out (which endings count as failed, the limit's design) is written by the
lead in ADR-0039 and its plan, not decided here.
