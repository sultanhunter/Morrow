# Typed boundaries and configuration contract
Canonical sequence26, P03.T02. 334 generated definitions (116 core/206 bodies/12 billing), 103 paired capability clients. Root contracts export types/version only; validator/client subpaths enforce the authoritative closed JSON Schema. Runtime validation covers safe integers, ranges, formats, conditional requirements, unknown fields and cross-schema references which structural TypeScript cannot express. Typed clients validate input/output through an injected authenticated transport; they do not implement endpoints, policy, credentials or permission to call anything.

Source generator resolves only reviewed local/registered references; no remote schema fetch. The manifest pins exact schema/source output hashes. `contracts:generate` regenerates types but never changes the compatibility freeze. `verify:boundaries` fails generated drift, any unreviewed schema delta and prohibited UI→server/Shopify imports (including export/dynamic paths). Initial version remains unreleased; any schema change requires explicit reviewed compatibility and migration evidence before deliberately updating release-baseline.json. Import rules are repository checks, not sandbox isolation. Package registry dependencies and production bundles need later supply-chain and deployment qualification.

Standalone domain UI imports only shared UI/types/entry ports, React and browser dependencies; no Shopify host SDK, server credential service or server environment. Neutral contracts never import an app. Shopify server composition root owns SDK configuration. API always obtains authenticated principal from qualified server identity and resolves current membership/installation itself; client shop/host flags never establish tenant authority.

Production session storage contract: durable PostgreSQL encrypted records and current installation/token revocation, refresh serialization, TTL and uninstall cleanup under tenant/account boundaries. Inject the SDK SessionStorage interface only after P04/P09 qualifies these semantics; no SQLite or in-memory production fallback. Required config: server-only key/secret, qualified HTTPS application URL, reviewed scopes/distribution/API version and storage dependency. Factory is not routed until those gates pass.

Private standalone/connector responses: no-store, no-referrer, nosniff; default frame-ancestors 'none'. Qualified Shopify connector surface may require SDK header changes after explicit UI/distribution review; no public embedded workspace exists. Production cookies need Secure/HttpOnly/path/SameSite and current-session/CSRF checks at actual authentication; no cookie is minted in this scaffold. Credentials come from a qualified server secret broker, never a Vite environment variable or browser storage. Public immutable assets and private entry/HTML remain different deployment responsibilities. Failed configuration denies rather than switching to synthetic authority.
