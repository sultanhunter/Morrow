## Security notes

- **The broker reads only what the lease names.** ModelCall@2 carries no conversation, so a compromised orchestrator cannot hand the broker a made-up history; the fake refuses a call whose run is not the one attached to the named context (one writer per context), so a valid lease cannot borrow another person's context. H7c's broker must keep both rules against SQL.
- **Permission and budget checks stay in code.** AgentRunSafety@1 lives in the manifest the model never sees; no contract the model reads names credits, a balance or a countdown; no notice code asks the model to wrap up.
- **No model-written authority.** Checkpoints, summaries and plans have no field that can claim an approval, consent, apply or payment; the ledger shows every operation whose outcome is unreconciled as UNKNOWN (`unknownOperationStatuses`: dispatching, submitted, verifying, uncertain and cancel_requested), so a compaction can never present one as settled; a review verdict can only block or raise no objection.
- **Read tags, audience, source subjects and taint on every stored derived row** (ADR-0041 item 25: checkpoints, the ledger, plans, review verdicts, summaries and notebook entries; result items are H5's), so a read can check the read tags, the reader's live view of every source subject and the audience; turns carry read tags, audience and taint. Taint is `DerivedTaint`, ModelUntrustedSource's kinds and a source count, joined by union and sum (`joinTaint`), so a reader of a stored row loses no kind. State blocks and search hits carry taint only: they are rendered for one reader after code has applied the audience and read-tag filter, and are never stored. Person memory has one principal and no admin path in its shape.
- **Every run has an absolute bound.** Every manifest kind names an envelope, upkeep included (admit_upkeep_run issues it and no act renews it), so no lease renews without an expiry; at every step's entry the lease kept covers the step (`leaseRenewalDue`), so the sweep cannot close healthy work `lease_lapsed` mid-call.
- **The broker's only source is SQL.** A provider compaction's opaque block is stored on its checkpoint (`block`), which the next epoch's opening names by id and digest; it is run content on its epoch's clock, deleted with the checkpoint and by redaction.
- Retired codes stay in the enums so old records still validate; `writableEndReason` stops new code writing them.

## Open questions and follow-ups

- **Owner to confirm or correct: the lead's reading of ADR-0041 item 13 for H5's checkpoint body (fix check N2).** Item 13 says model-written decisions "become discussed items, each with an exact quote", and the validator checks stated states. H5's `context.checkpoint` input (the stored fallback body) has neither a quote nor a stated state.
