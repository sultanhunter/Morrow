## Goal

Make credits the only spend limit for Listings runs and the computer, as ADR-0039 items 1, 4 and 6 say, and put Listings on Claude Opus 5.5 only, as the owner decided on 2026-10-26: no US$7 run cap, no US$25 daily cap, no US$10 monthly runtime budget. A Listings run still holds its products × credits per product from the wallet before any call, so it never runs out mid-run, and admits up to 25 products for every entry. Non-money limits stay: 25 products, two attempts a product, the three-failure breaker, 10 sandboxes at once and 3 per workspace, each sandbox's deadline. The outside backstops are the owner's Anthropic monthly limit (US$100) and E2B's usage limit, whose refusal sets the runtime hold.
