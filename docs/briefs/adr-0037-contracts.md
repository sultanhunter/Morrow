## Security notes

- **Depth 1:** the generator refuses an `agent.*`, delegation or `agents.*` tool outside the Coordinator's context, and package checks refuse such a tool or capability on any other package; no card may pick one.
- **A called teammate cannot talk to the person:** the call context never offers a question or a post, and the generator refuses one there.
- **No model-written authority:** `agent.propose` is the one input that names tools, by `ToolName` only (a reviewed exception to the forbidden-field rule); code derives every capability, scope, data class and limit, the store and model come from server facts, and an edit only narrows. A card holds no code, URL, credential or money field. The package checks hold a workspace package to exactly the grants its tools derive (no wider capability, verb or scope, `read_customers` included), and neither the document nor the package is built from a card whose grants are not its tools'.
- **Digest-bound approval:** `addToTeamDocument` computes the card's digest itself, so the document cannot list one card's grants under another digest; a workspace package's `roleTextDigest` binds its instructions and skill text, so a change to either after approval fails the package checks; an ineligible skill fails them too.
- **Tenancy:** a card revision records only an editor of the card's organization and workspace (editors join item 5's conflict set), the same rule as the document's actor.
- **Taint only joins:** a call a tainted run makes starts tainted (`joinRunTaint`), and the fake runner carries the caller's taint into the called run's items and result.
- **Item 5 exclusions:** never `human_only` (any verb), `workspace.task.delegate`, `agents.*`, `support.*`, Level 2 or the inbound-mail trigger on a card or workspace package; the four Owner-only kinds are derived in code.
- **Results and items:** closed, wrapped as tainting data (`teammate_result`, `result_item` sources); nothing customer-tagged enters Morrow's context; an item opens for Morrow only from a result its own run received, and for a teammate only when also named in its brief; an unknown id reads as not received.
- **No character cap, no truncation:** the 8 KiB tool-result bound stays; what does not fit becomes an item, pages count JSON escapes, and nothing is cut. Morrow's output tokens per turn bound a brief.
- **Default off; no money cap:** both switches off with `edge:check` guards; the fake runner asks only whether the balance covers a call.
