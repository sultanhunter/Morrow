# P05.T01w Genuine Firefox transport prerequisite (deferred)

Status: deferred by ADR-0003 (Owner approval, 2026-10-17). No code, tests or outputs in this release.

The original packet text exists only in sequence 95 of the frozen ChatGPT Page. Its intent:

- Prove that a genuine browser engine, not only HTTP cookie jars and Node fixtures, honours the delivered `__Host-morrow_session` cookie: Secure, HttpOnly, SameSite=Lax and Path=/ across login, bootstrap and logout.
- Run a genuine Firefox in a Playwright container that trusts a synthetic NSS root certificate, so the cookie rules apply on a TLS origin.
- Test only: no product behaviour changes. The previous agent began it in a private working copy and never committed it; nothing from that copy is imported.

Replacement: the real-browser Playwright login, bootstrap and logout smoke against the hosted staging origin in P04.T01i (M1) proves the same cookie behaviour on a real HTTPS origin. P05 qualification does not wait for this child (plan, Package 05 "Qualification").
