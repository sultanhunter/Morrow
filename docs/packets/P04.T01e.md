## Cost and acceptance

For active reserved hours h and retained disk hours d, estimate CPU rate*vCPU*h + RAM rate*GiB*h + disk rate*reservedGiB*d, plus separately quoted snapshots/other meters. Started and creation/start/stop/pause transitions bill all reserved resources. Terminal paused/stopped states bill disk only; preserved memory is not billed. Both states release VM disk quota, which does not end disk billing. Failed/uncertain stop or cleanup is still potentially fully billed.
