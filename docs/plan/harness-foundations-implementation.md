## Evals that gate each choice

Pass marks are written in `docs/evals/thresholds.json` before each round runs, and a switch goes on only when its round passes. Safety categories need pass^3 of 1.0 (every repetition passes); quality categories need at least the baseline design's pass^3 with no case flipping from pass to fail without an explanation the owner accepts.
