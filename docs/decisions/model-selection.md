# Model gateway design

Decision: ADR-0022 items 10, 11 and 16 (owner, 2026-10-19). It replaces the 2026-10-14 selection of OpenAI for text models (canonical sequence 16). The machine-checked record is `model-policy.json`; `npm run verify` validates it.

**Provider-neutral port.** Callers send `ModelCall@1` and receive `ModelResult@1` through the broker; neither names a provider, provider model ID, token limit or price. In the broker, each catalogue entry names a `ModelProvider` adapter that maps the call to the provider's request and the reply back to `ModelResult@1`. Anthropic Claude, through the Messages API, is the first and only adapter. Another LLM is one adapter, one broker credential and one catalogue entry with no change to callers; selecting it is material and needs an owner-approved ADR. There is no automatic fallback to another model or provider, and Anthropic's server-side `fallbacks` parameter is not used.

**Catalogue and selection.** A versioned catalogue lists the allowed models (`claude_haiku_5_5`, `claude_sonnet_5_5`, `claude_opus_5_5`) and efforts (`low`, `medium`, `high`, each mapped to adaptive thinking, `output_config.effort` and a `max_tokens` cap). The workspace sets a default (Sonnet 5.5, low effort); a merchant may pick another entry per run. The server accepts only catalogue keys, never a model string from the client. Model IDs are Anthropic's pinned snapshot IDs; a new model or price is a new catalogue version, and runs record the version they used. [Claude models](https://platform.claude.com/docs/en/about-claude/models/overview), [effort](https://platform.claude.com/docs/en/build-with-claude/effort)

**Cost.** One credit drafts one product at the default; other entries cost a published multiplier (1–6 credits). Thinking tokens are billed as output and count toward `max_tokens`. Per-call input and output caps, two attempts per product, US$7 per run, US$25 per workspace per day and the Anthropic Console workspace's monthly spend limit bound spend whatever the selection. The verifier rejects any entry whose worst case per product exceeds its credits' revenue on the beta plan. Prices are list prices observed on 2026-10-19, not a merchant invoice rate. [Pricing](https://platform.claude.com/docs/en/about-claude/pricing)

**Data.** Only the merchant's request text and the product's catalogue fields are sent. Anthropic does not train on commercial API data by default, deletes API inputs and outputs within 30 days (longer only if flagged by its trust and safety systems), and offers zero data retention only by agreement, which Morrow does not have. Stateful provider features (Files, Batches, code execution, Managed Agents) are not used for merchant content. [API and data retention](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention)

**Images.** Claude does not generate images. The post-launch image capabilities (P17.T02e) keep the recorded OpenAI Images selection (GPT Image 2.5 Sunburst) behind the same port until an owner ADR decides otherwise; no OpenAI credential is bound for the MVP. [Images guide](https://developers.openai.com/api/docs/guides/image-generation)

No model may mint a capability, approval, billing entitlement, credential or its own model selection. Coordinator discovery sees capability metadata allowed by current actor scope; subagents receive authorized contextual references, tool discovery, mandates and budgets. API observations with web search record prompt, locale, model, date and cited evidence; they do not measure consumer chatbot market share or promise citations.

P13 evaluation uses held-out small-brand and specialist tasks, repeats, missing context, conflicting source evidence, malicious retrieved instructions, revocation, refusal, unknown provider effects and recovery. Critical authority failures have zero tolerance. Each role's output, correction effort, completion, latency and total-cost thresholds must be fixed before its trial. No model quality or merchant value has been measured yet; the expected token counts in the catalogue are estimates until the staging smoke runs replace them. P15 researches and releases skills; evaluation evidence links exact model, effort, catalogue version, route, skill, connector and workflow versions.
