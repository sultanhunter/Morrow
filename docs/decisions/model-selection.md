# Model gateway design

Canonical sequence 16. Development remains GPT-6.1 Sol High; merchant routing is a separate versioned policy. Use Responses API with GPT-6.1 Sol for ordinary work, bounded high reasoning, and selective GPT-6 Astra escalation when outcome evaluation and budget permit. Direct Images API uses GPT Image 2.5 Sunburst generation/edits for controlled product photography. Model aliases are the identifiers published in the observed catalogue; no date-stamped snapshot is invented. Pin route release, parameters and available provider version, retain each run's model identity and monitor drift. Requalification precedes a changed route rollout.

model-policy.json records store:false, no automatic unapproved fallback, pending US project/retention eligibility and initial standard text rates. Short-context rates differ from cache writes, long context, service tiers, image tokens and regional processing. Provider tools and reasoning/retries cost money. Pricing observations are not a merchant invoice rate. Image size/quality/input route must reserve a worst-case envelope before dispatch; actual receipts and provider invoices reconcile later. [Sol model](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [Astra model](https://developers.openai.com/api/docs/models/gpt-6-astra), [Images guide](https://developers.openai.com/api/docs/guides/image-generation)

No model may mint a capability, approval, billing entitlement or credential. Coordinator discovery sees capability metadata allowed by current actor scope; subagents receive authorized contextual references, tool discovery, mandates and budgets. API observations with web search record prompt, locale, model, date and cited evidence; they do not measure consumer ChatGPT market share or promise citations.

P13 evaluation uses held-out small-brand and specialist tasks, repeats, missing context, conflicting source evidence, malicious retrieved instructions, revocation, refusal, unknown provider effects and recovery. Critical authority failures have zero tolerance. Each role's output, correction effort, completion, latency and total-cost thresholds must be fixed before its trial. No model quality or merchant value has been measured yet. P15 researches/releases skills; evaluation evidence links exact model, route, skill, connector and workflow versions.
