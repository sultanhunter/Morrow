## P01.T02a follow-up: proposals without a task (ADR-0018)

Status: implemented on `claude/p01-t02a-c-proposal-task-optional`, from `main` `400aa44`, as the deliberate v1.1 candidate edit that ADR-0018 item 5 requires before P06.T01b PR-1 merges. Proposal@2 `taskId` is `Id | null`. A null task requires a `governance.*` capability and a `HumanActorRef` proposer (schema `allOf` rule), and the catalogue's Governance domain (`checkProposal`, `TASK_REQUIRED`). `ProposalFacts` carries the producer's `taskId`, with a null `requestedBy` exactly when there is no task (the `ProposalTaskFacts` union, also checked at runtime); `checkProposal` binds the proposal's task to it (`TASK_MISMATCH`) and, without a task, requires `requestedBy` to be the proposer, who therefore stays in the conflict set. JSON Schema cannot express that equality, so schema validity alone does not establish ADR-0018 compliance. The Tier 2 AI review (separate context, same model family) findings were applied in `Address review findings for adr18`.
