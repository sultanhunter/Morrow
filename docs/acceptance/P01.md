## P01.T02a follow-up: proposals without a task (ADR-0018)

Status: implemented on `claude/p01-t02a-c-proposal-task-optional`, from `main` `400aa44`, as the deliberate v1.1 candidate edit that ADR-0018 item 5 requires before P06.T01b PR-1 merges. Proposal@2 `taskId` is `Id | null`. A null task requires a `governance.*` capability and a `HumanActorRef` proposer (schema `allOf` rule), and the catalogue's Governance domain (`checkProposal`, `TASK_REQUIRED`). `ProposalFacts` carries the producer's `taskId`, with a null `requestedBy` exactly when there is no task (the `ProposalTaskFacts` union, also checked at runtime); `checkProposal` binds the proposal's task to it (`TASK_MISMATCH`) and, without a task, requires `requestedBy` to be the proposer, who therefore stays in the conflict set. JSON Schema cannot express that equality, so schema validity alone does not establish ADR-0018 compliance. The Tier 2 AI review (separate context, same model family) findings were applied in `Address review findings for adr18`. Local checks after them passed: `npm run typecheck` (with `packages/policy/src/typechecks.fixture.ts`), `npm run format:check`, `npm run verify` (337 contract cases), the targeted unit tests (697 tests in `review-policy`, `contracts`, `contract-versioning`, `runtime-validation`, `typed-boundaries`, `foundation`, `policy`, `kill-switch`, `agent-authority`, `ci-workflow` and `plan-check`) and `npm run lab:workers` (5,475 validator cases over 365 selectors; 7 review previews equal to Node). The full `npm test`, `npm run ci` and `npm run smoke:scaffold` were not run locally because of machine load; hosted CI is the authority. Still open, so nothing here is Verified: recording the Tier 2 review and `/security-review` on the PR; hosted CI; the Tier 3 P01 contract sign-off.

Contract v1.1 after this edit: 21 core-v1.1 definitions, 365 generated validators (bundle 1,839,814 bytes) and 337 contract cases (P01.A02 plus 118 in `P01.T02a.json`).
